# Agendamento da Quadra

Projeto desenvolvido para organizar os horários de uso da quadra do Condomínio Moradas Sul.

O sistema permite que os moradores façam o agendamento escolhendo a data e o horário desejado.

## Funcionalidades

- Realizar agendamento
- Escolher data e horário
- Gerar um código para editar ou cancelar o agendamento
- Compartilhar o código pelo WhatsApp
- Enviar feedback
- Visualizar os feedbacks enviados
- Baixar agendamentos em CSV
- Baixar feedbacks em CSV

## Tecnologias utilizadas

- Python
- Flask
- HTML
- CSS
- Banco de dados
- Render

## Acesso ao projeto

O projeto está hospedado no Render.

## Objetivo

O objetivo é facilitar a organização dos horários da quadra e evitar conflitos entre os agendamentos.
